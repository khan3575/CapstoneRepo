## 1. ✅ Centralized Configuration System

### Created `config.yaml`
- **Location**: `/mnt/bigdata/capstone/brats_gnn_segmentation/config.yaml`
- **Purpose**: Single source of truth for all paths and hyperparameters
- **Benefits**:
  - Easy adaptation to different systems
  - No more hardcoded paths in code
  - Consistent configuration across all scripts

### Created `src/config.py`
- **Location**: `/mnt/bigdata/capstone/brats_gnn_segmentation/src/config.py`
- **Purpose**: Configuration loader module
- **Features**:
  - Automatic path resolution (relative → absolute)
  - Dot-notation access (e.g., `config.get('model.gnn.hidden_channels')`)
  - Convenience properties for common paths
  - Global singleton pattern for easy import

### Example Usage:
```python
from config import get_config

config = get_config()
graphs_path = config.data_graphs  # No more hardcoded paths!
batch_size = config.get('model.training.batch_size', 32)
```

## 7. 🚀 How to Use the New System

### For Users on Different Systems:
1. **Edit `config.yaml`:**
   ```bash
   nano config.yaml
   ```

2. **Update your BraTS data paths:**
   ```yaml
   paths:
     brats_2021_raw: "/YOUR/PATH/TO/BraTS2021_Training_Data"
   ```

3. **Run scripts normally:**
   ```bash
   # All paths come from config.yaml automatically
   python src/train_cv_fold.py --fold_idx 0
   ```

### Override Config from Command Line:
```bash
# Use config defaults
python src/train_cv_fold.py --fold_idx 0

# Override specific settings
python src/train_cv_fold.py --fold_idx 0 --batch_size 64 --epochs 100
```
